# Show Docker Version

Displays the installed Docker version.

```bash
docker --version
```

---

# Display Docker System Information

Shows detailed information about Docker.

```bash
docker info
```

---

# Download an Image

Downloads an image from Docker Hub.

```bash
docker pull ubuntu
```

---

# List All Images

Displays all downloaded Docker images.

```bash
docker images
```

---

# Remove an Image

Deletes a Docker image.

```bash
docker rmi ubuntu
```

---

# Build an Image

Builds a Docker image from a Dockerfile.

```bash
docker build -t myimage .
```

---

# Run a Container

Creates and starts a new container.

```bash
docker run ubuntu
```

---

# Run Container Interactively

Starts a container with terminal access.

```bash
docker run -it ubuntu
```

---

# Run Container in Background

Runs a container in detached mode.

```bash
docker run -d nginx
```

---

# List Running Containers

Shows only running containers.

```bash
docker ps
```

---

# List All Containers

Shows both running and stopped containers.

```bash
docker ps -a
```

---

# Start a Container

Starts a stopped container.

```bash
docker start <container_id>
```

---

# Stop a Container

Stops a running container.

```bash
docker stop <container_id>
```

---

# Restart a Container

Restarts a container.

```bash
docker restart <container_id>
```

---

# Remove a Container

Deletes a stopped container.

```bash
docker rm <container_id>
```

---

# Force Remove a Running Container

Stops and removes a running container.

```bash
docker rm -f <container_id>
```

---

# Open Bash Inside a Container

Accesses the container terminal.

```bash
docker exec -it <container_id> bash
```

---

# View Container Logs

Displays logs generated by a container.

```bash
docker logs <container_id>
```

---

# Show Running Processes Inside Container

Displays active processes inside a container.

```bash
docker top <container_id>
```

---

# Show Container Details

Displays detailed information about a container.

```bash
docker inspect <container_id>
```

---

# Rename a Container

Changes the container name.

```bash
docker rename old_name new_name
```

---

# Copy File from Host to Container

Copies a file into a container.

```bash
docker cp file.txt <container_id>:/home/
```

---

# Copy File from Container to Host

Copies a file from a container to the host.

```bash
docker cp <container_id>:/home/file.txt .
```

---

# List Docker Volumes

Displays all Docker volumes.

```bash
docker volume ls
```

---

# Create a Volume

Creates a new Docker volume.

```bash
docker volume create myvolume
```

---

# Remove a Volume

Deletes a Docker volume.

```bash
docker volume rm myvolume
```

---

# List Docker Networks

Displays all Docker networks.

```bash
docker network ls
```

---

# Create a Network

Creates a new Docker network.

```bash
docker network create mynetwork
```

---

# Remove a Network

Deletes a Docker network.

```bash
docker network rm mynetwork
```

---

# List Docker Images, Containers, Volumes & Networks

Displays Docker resource usage.

```bash
docker system df
```

---

# Remove Unused Docker Resources

Deletes unused images, containers, networks and cache.

```bash
docker system prune
```

---

# Remove Everything Unused

Deletes all unused Docker resources including images and volumes.

```bash
docker system prune -a
```

---

# Login to Docker Hub

Logs into your Docker Hub account.

```bash
docker login
```

---

# Push Image to Docker Hub

Uploads an image to Docker Hub.

```bash
docker push username/image:tag
```

---

# Search Images on Docker Hub

Searches for images.

```bash
docker search nginx
```

---

# Show Docker Events

Displays real-time Docker events.

```bash
docker events
```

---

# Show Docker Resource Usage

Displays CPU, RAM and Network usage of running containers.

```bash
docker stats
```

---

# Execute Any Command Inside Container

Runs a command inside a running container.

```bash
docker exec <container_id> ls
```

---

# Display Docker Compose Services

Lists services managed by Docker Compose.

```bash
docker compose ps
```

---

# Start Docker Compose Services

Starts all services defined in docker-compose.yml.

```bash
docker compose up
```

---

# Start Compose in Background

Starts all services in detached mode.

```bash
docker compose up -d
```

---

# Stop Docker Compose Services

Stops all running compose services.

```bash
docker compose down
```
