# Common Directories
---
# / (Root)
- Top level of Linux, Starting Point
  
# /bin (Binaries)
- Executable Programs, The commands we run are stored in it.
  
# /etc (Config Files)
- System setting, users list, network setting

# /var (Variable Data)
- Dynamic data such as log files

# /home (Home Directory)
- Every user have their own home directory

# /usr (User programs)
- Pre installed system softwares

# /opt (Third Party Software
- The software downloaded by user are stored here.

# /tmp (Temporary files)
- We run a program, RAM Used

# /boot
- Important system files required for starting a system)

# /dev (Hardware devices)
- Devices files 

# /proc (Virtual)
- Live Processes info
---
# Sensitive Files
---
# /etc/passwd
-User Info

# /etc/shadow
- Encrypted password hash stored

# /etc/crontab
- System cronjobs

# /etc/log/syslog
- System overall activity log
---

# /etc/sudoers
- shows Which User can use sudo

# /etc/log/auth.log
- Login attempts
